Arsalan Ultimate Scientific Calculator (Pro 600+)
An advanced, mobile-responsive, and professional scientific calculator inspired by the sleek iOS design language. This project is built using modern web technologies: HTML5, CSS3, and JavaScript.

🚀 Key Features
iOS-Inspired UI: Features a sleek, modern dark-mode interface that provides users with a premium mobile application experience.

600+ Functions Support: Powered by the JavaScript Math object and a robust eval() engine, allowing for complex scientific calculations including Trigonometry, Logarithms, and Advanced Algebra.

Intelligent Shift Mode: Includes a 'Shift' feature to double the functionality of buttons (e.g., toggling between sin and sin⁻¹), mimicking high-end physical scientific calculators.

Dynamic Calculation History: A built-in history panel that automatically records and displays previous calculations for quick reference.

Fully Responsive Design: Optimized for all screen sizes—from desktops and tablets to small mobile devices—using CSS Grid and Flexbox.

🛠️ Technologies Used
HTML5: Used for semantic structure and accessible input handling.

CSS3 (Grid & Flexbox): Utilized for the sophisticated layout, iOS-style aesthetics, and ensuring a mobile-first responsive design.

JavaScript (ES6): The "brain" of the app, handling the calculation logic, state management for Shift mode, and dynamic DOM manipulation for the history logs.

📖 How to Use Shift Mode
Enter Value: Type your number or expression into the input field.

Toggle Shift: Press the 'Shift' button. The button will change color (to yellow), and an 'S' indicator will appear on the display.

Execute Function: Press any scientific button (e.g., sin, cos, or log). The calculator will automatically execute the inverse or secondary function (e.g., asin, acos, or ln).
